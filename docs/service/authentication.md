# 鉴权

## 用户 API key

用户在每个请求中提交：

```text
X-API-Key: limem_<token>
```

API key 本身就是用户身份。一把 key 可以校验 Session 格式，并且只能创建、列出、
写入和检索自己的记忆库。访问其他 key 的记忆库与访问不存在的记忆库一样返回
`404`。

服务不会再次返回已经签发过的明文 key。管理员可以列出 `key_id`、名称、状态和
时间，但不能查看明文或 hash。

## 管理员 API key

管理员 key 可以：

- 签发和列出用户 key；
- 撤销用户 key；
- 检索或删除已知 ID 的任意记忆库。

管理员不能以用户身份创建、列出或写入记忆库。

撤销用户 key 是不可恢复的操作。服务先使 key 失效，再同步删除该 key 名下所有
临时库、长期库和原始 Session。签发记录保留为 `revoked`。
